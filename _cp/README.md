# Virtual Embryo community projects

Three small tools I ended up wanting while working with the Virtual Embryo Challenge. They are kept together because each solves a fairly narrow problem.

- **[ML Guide](ml-guide/)** — for ML entrants who can follow the submission docs but still do not have a good mental model of the data or prediction target.
- **[Data Safety Kit](data-safety/)** — checks the mechanically clear parts of the external-data rules and helps keep a usable source disclosure.
- **[Metric Lens](metric-lens/)** — turns a local `veckit` metric vector into its public weighted score contributions and simple one-metric counterfactuals.

The more substantial experiments live separately:

- [Intuition Lab](https://github.com/i-habib/virtual-embryo-community/tree/main/intuition-lab)
- [External Data Catalog](https://github.com/i-habib/external-data-catalog)

Everything here is independent community tooling. For rules, scoring contracts, and submission requirements, use the official challenge site and scorer.
